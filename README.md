# Callahan Culinary Creations

A Jekyll recipe site built with the Minima theme and GitHub Pages.

## Styling update
The custom design is in `assets/main.scss`. Jekyll compiles it to
`assets/main.css` and loads it through `_includes/head.html`.

The homepage in `index.html` keeps the existing Jekyll paginator and each
recipe's original `post.url`, image, tags, and description. Search and tag
pages remain in place.

## Publish
Commit and push the updated files to the repository. GitHub Pages will build
the Jekyll site automatically.
